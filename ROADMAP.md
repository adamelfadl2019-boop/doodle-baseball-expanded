# Roadmap

The big “add everything” phase is over. V19 is public, so the roadmap is now based on what actually happens when people play it.

## Right now

### 1. Real-world testing
- Fresh-install testing on clean folders.
- Browser/Windows compatibility checks.
- Watch for launcher path and local-server problems.
- Fix reproducible crashes or broken states first.

### 2. Baseball polish
- Tune defense timing when real playtests expose bad SAFE/OUT calls.
- Improve foul behavior and edge cases.
- Polish visual feedback where a mechanic works but is hard to read.
- Keep the original game's feel recognizable.

### 3. Pitch quality
- Balance signature pitches that are unfair for the wrong reason.
- Prefer memorable movement over inflated counts.
- Add new handcrafted pitches only when they have a clear identity.

## Good candidates for later versions

- Better challenge/campaign presentation.
- More handcrafted boss encounters.
- More useful progression rewards.
- Additional accessibility/settings options.
- Better in-game explanations for complicated modes.
- Animation/feedback polish around defense and close plays.

## Things I do not want this project to become

- A race to claim a larger pitch count.
- Hundreds of recolors or renamed clones.
- A rewrite of the original game from scratch.
- A repository that bundles third-party game assets it does not own.
- A giant update that breaks stable systems for one flashy feature.

If a future V20 happens, it should be because there is enough real improvement to justify calling it V20.
