# Security

Doodle Baseball Expanded runs a local Python HTTP server bound to `127.0.0.1` and works on copies of local game files.

## Expected behavior

- The mod should not require administrator privileges.
- The local server should stay bound to localhost.
- The launcher should not need passwords, account tokens, or other private credentials.
- Debug reports should not intentionally collect personal data.

## Reporting a security problem

For a security-sensitive problem, avoid posting exploit details, passwords, tokens, or private filesystem information in a public issue.

For normal crashes, installation problems, or gameplay bugs, use the standard bug-report form instead.
