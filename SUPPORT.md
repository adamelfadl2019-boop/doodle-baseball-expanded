# Getting help

## Installation / launcher problems

First run:

```bash
python launcher.py --diagnose
```

If your game files are in a specific folder:

```bash
python launcher.py --diagnose --repo "C:/path/to/game/repo"
```

If the launcher creates `DBE_LAST_ERROR.txt`, include its contents in your bug report.

## In-game bugs

Press **F9**.

The debug tools can generate useful information about the current pitch, mode, fielders, and recent events.

Then open a bug report:

https://github.com/adamelfadl2019-boop/doodle-baseball-expanded/issues/new/choose

## Feature ideas

Use the feature-request form:

https://github.com/adamelfadl2019-boop/doodle-baseball-expanded/issues/new/choose

Please explain what the feature would make better, not just what it would add.

## Privacy

Do not post passwords, tokens, private account information, or personal filesystem details in a public issue.
