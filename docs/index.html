Doodle Baseball Expanded

Remember Google Doodle Baseball? I wanted to see how far I could push it without replacing what made the original fun.

The mod keeps the original game underneath, then adds 3,000 named pitches, 16 movement variants, new modes, progression, defense, achievements and a lot of completely ridiculous baseball.

Why does this exist?

Honestly, this started because I wanted more pitches.

The original game is tiny, simple and really fun, and I kept wondering what it would be like if it had actual progression and increasingly stupid pitches instead of ending there.

That eventually turned into Doodle Baseball Expanded. V19 is way bigger than the first idea: thousands of pitch identities, challenge modes, mastery, achievements, fielding changes and enough debugging tools to tell me exactly what I broke.

3,000 pitches. Some of them are normal.

The catalog starts with actual baseball ideas: Four-Seam Fastball, Cutter, Sinker, Slider, Sweeper, 12–6 Curveball, Splitter, Knuckleball and more.

Then the rules get less reasonable.

Magic Zoomball. Black Hole. Gravity Flip. Teleport Curve. Time Freeze. Glitchball. Vortex Cannon. Chaos Comet.

The first 50 signatures have handcrafted movement identities, and the full pool feeds into the mod's challenge systems.

PITCH NOTES

#023 — Black Hole

Category: Cosmic
Style: Gravity / Drop
Idea: the ball tightens into a gravity-like spiral on its way to the plate.

If it looks normal at first, that does not mean it is.

MODE

Perfectionism

98%+ contact keeps the precision streak alive and builds a grade from D toward S+.

One imperfect contact breaks it.

Normal contact isn't enough here.

Perfectionism exists because normal endless scoring eventually stops being stressful. This mode watches the quality of the contact itself.

Boss Ladder goes the other direction: it takes the 50 signature pitches and makes you beat them one at a time. You do not advance because you survived. You advance by hitting a home run.

Defense actually matters now.

The original game was never really designed around full defensive baseball. Expanded hooks into the real peanut fielders and adds fly catches, throws to first, runner-versus-throw races, wall rebounds, foul territory and close SAFE/OUT calls.

This is also one of the systems I watch most closely for bugs, because modifying an old browser game's baseball lifecycle gets weird very quickly.

FIELDING

What can happen?

Peanut pickup → determine fly/ground state → throw race → SAFE or OUT.

The mod tries to consume those results inside the game's normal lifecycle instead of brute-forcing the batter out of existence.

Yes, there is progression now.

I did not want the pitch count to exist just so the README could say “3,000.” Pitches feed into challenge modes, mastery medals, achievements, mission boards and a 48,000-combination Gauntlet.

Some of it is completely unnecessary. That's kind of the point.

I also gave the baseball game a debug console.

Press F9 and the mod can show the current pitch, variant, mode, fielding bridge, FPS and recent event history. The full DEBUG page can run self-checks and prepare information for a GitHub issue.

Installing the mod

  1. Download V19.
    Grab the installer ZIP from the latest GitHub Release.
  2. Extract it.
    Do not run the launcher from inside the ZIP.
  3. Start the launcher.
    On Windows run START_REAL_MOD.bat, or use python launcher.py.
  4. Play.
    The launcher creates separate modded launch files and starts the game locally.

Your original game.js is not overwritten.

Found something broken?

Please report it. This mod changes parts of a game that were never designed for any of this, so weird edge cases are absolutely possible.

If you find one, press F9 first. The debug tools can give you most of the information needed to track it down.
